# ?? Chess Application - Simple Distribution

## ?? Quick Start

### Windows
```
1. Extract the Chess folder
2. Double-click: RUN_CHESS.bat
3. Chess launches! ??
```

### macOS/Linux
```bash
# In terminal:
chmod +x RUN_CHESS.sh
./RUN_CHESS.sh
# Chess launches! ??
```

---

## ? Requirements

All platforms need **ONE TIME** setup:

1. **.NET 8 Runtime** 
   - Download: https://dotnet.microsoft.com/download/dotnet/8.0
   - Install and restart

2. **Stockfish Engine** (for AI gameplay)
   - Download: https://stockfishchess.org/download/
   - Extract to known location
   - Update path in Chess config if needed

## ? Troubleshooting

**"Chess.exe not found"**
- Make sure you extracted the full Chess folder
- Don't move files around

**".NET Runtime not installed"**
- Download from: https://dotnet.microsoft.com/download/dotnet/8.0
- Install and restart your computer
- Try launching again

**"Stockfish not found"**
- Download from: https://stockfishchess.org/download/
- Extract to a known location
- The app will prompt you to set the path

**Permission Denied (macOS/Linux)**
```bash
chmod +x RUN_CHESS.sh
```
